تثبيت وصيانة ProERP

اختر العملية، ثم انسخ الأمر وشغّله في PowerShell كمسؤول.

مهم: المتصفح لا يستطيع تثبيت البرامج مباشرة لأسباب أمنية. هذه الصفحة تنشئ لك الأمر الصحيح، بينما السكربت الموقّع يتولى التنزيل والتحقق والتثبيت.

القائمة الكاملة

يعرض جميع عمليات التثبيت والتحديث والصيانة.
تنزيل السكربت
  1. افتح قائمة Start وابحث عن PowerShell.
  2. اختر Run as administrator.
  3. الصق الأمر واضغط Enter، وستظهر نسبة التنزيل والوقت المتبقي.
