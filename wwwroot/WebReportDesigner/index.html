ملفات المصمم مفقودة

البنية التحتية البرمجية للـ API جاهزة تماماً للعمل، ولكن ملفات الواجهة الخاصة بـ FastReport Online Designer غير موجودة في المشروع حالياً.

لتفعيل المصمم، يرجى تحميل مجلد WebReportDesigner من حسابك في FastReport ووضع كافة محتوياته (HTML / CSS / JS) داخل المسار التالي في السيرفر:

wwwroot / WebReportDesigner
